# Floresta Viva

Experiência digital artística e cinematográfica sobre o bioma Amazônia, construída como um projeto de desenvolvimento criativo e direção visual.

## Tecnologias

- Next.js com App Router
- React e TypeScript
- GSAP e ScrollTrigger
- Lenis
- SCSS Modules

## Executando localmente

```bash
cd site
npm install
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## Verificações

```bash
cd site
npm run lint
npm run build
```
